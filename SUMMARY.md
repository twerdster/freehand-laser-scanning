# Freehand Laser Scanning: project state

Research source for Ron Slossberg, Aaron Wetzler and Ron Kimmel’s BMVC 2015 laser-scanning method, plus a runnable 2026 adapter of its central stages. Keep this project distinct from Freehand Voxel Carving.

The recovery imports 181 source/config/license instances: MATLAB experiments, classification wrappers, separately licensed helpers, a sanitized 2014 iOS MIT sample-derived implementation, six historical source/config snapshots and an older C++ backup. Imported bytes and published hashes in docs/SOURCE_MANIFEST.json remain intact. Original Git lacks one tree and six blobs, but every selected published source blob was readable. HISTORY.json records source commits. SDK keys, signing settings, private build paths and one hardcoded email recipient were removed only by the documented publication edits.

`updated/` now contains Python and native Accelerate C adapters for paired multiscale filters, five-sample cubic ridge fitting, camera-frame laser calibration and ray/plane reconstruction. It supplies synthetic camera poses explicitly; it does not implement the proprietary tracker, live capture or historical texture integration. New centered/L1-normalized filter kernels, grayscale gamma 12/threshold 8, column peak convention, centered SVD and safety guards are documented in updated/README.md. A literal archived-kernel diagnostic remains separately labelled. Original code is unmodified.

The independent generator ray-casts plane, sphere, fold and calibration-board surfaces and illuminates by attached laser-plane distance. The public fixture has six calibration and sixteen scan PNGs (160×120), seeded noise, three occlusion frames and a nonlaser distractor. Artifacts include metrics, continuous true-curve pixel/Euclidean errors and recall, false accepted counts, pose sensitivity, frame/response montage, geometry/error plots, per-frame points and PLY. Successful-scene surface RMSE is approximately 2–3 mm; the distractor fails at approximately 744 mm. These are bounded synthetic results, not paper measurements or real scanner accuracy.

The new unsigned SwiftUI/SceneKit app `updated/ios/FreehandReplay.xcodeproj` compiles the same C core, processes bundled PNGs/poses, calibrates and reconstructs on launch, and exports Documents/native-validation.json. Bundle ID org.freehandlaser.Replay. Xcode 16.1/iOS 18.1 simulator build, installation and execution succeed without signing/accounts. The actual app’s 16 frames/2094 points match the desktop adapter within 8.4e-9 m per world coordinate. Picker, accumulation, fold occlusion, distractor warning, useful curved-cloud framing, button rotation and reset were visibly checked; drag is implemented but not verified by the automation tool. A fresh terminate/relaunch regenerated byte-identical numerical output and passed parity again. No simulator boot/device lifecycle is part of routine checks. The initial historical PointCloudSample unsigned build failed (exit 65) on missing resources; obsolete deployment/architecture warnings and separately missing SDK dependencies are documented in docs/BUILD_ATTEMPT_2026-11-15.md. No original MATLAB execution, hardware test or scientific reproduction is claimed.

Validation commands: `python3 scripts/verify_sources.py`; `python -m updated.run_simulation`; `python -m updated.run_checks` (macOS native parity + ASan/UBSan), or `--python-only` elsewhere. The new checks cover invalid rigs, nonfinite data, grazing/negative/deep rays, cubic/line/border degeneracy, noisy single-pose calibration, moving calibration/scan rigs, occlusion, distractor, external metric scale and timing sensitivity; updated/validation/checks.json binds tested source/fixture hashes and results. Historical static checks parsed 18 MATLAB files with MISS_HIT 0.9.44 and 14 Apple configuration files. See docs/VALIDATION.md for scope.

Kitware helpers retain Apache 2.0; MATLAB helpers keep separate terms including Mian’s research-use restriction. No blanket historical license. Newly authored adapter/generated assets under updated/ use their scoped MIT grant with 13th Lab sample attribution.
